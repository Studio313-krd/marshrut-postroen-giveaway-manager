# Конкурсы Маршрут-Построен

Закрытое приложение для менеджеров: импорт готового Excel с комментариями, промпт для проверки через ИИ, случайный розыгрыш с записью видео и архив. Авторизация — admin. Внешняя программа получения комментариев работает отдельно от сервиса.

## Работа менеджера

1. Установите расширение [GramLens](https://gramlens.com/ru) в Chrome и войдите в Instagram. Выгрузите все комментарии нужной публикации в Excel (.xlsx), включая повторные аккаунты и ответы.
2. «Провести новый конкурс» → загрузка исходного .xlsx. Конкурс создаётся сразу после успешной загрузки файла, без ввода ссылки. Поддерживаются столбцы **Имя пользователя / Текст комментария** (в том числе девять столбцов GramLens) и **Аккаунт / Комментарий**. Переименовывать или удалять дополнительные столбцы не требуется. Сверьте число комментариев и аккаунтов.
3. Введите полные условия и нажмите «Создать промпт». Он учитывает формат, название и число строк исходного Excel.
4. Прикрепите **тот же исходный Excel из GramLens** к промпту в ChatGPT с анализом файлов. Просмотрите отчёт и решите спорные случаи. Получите новый Excel с допущенными аккаунтами: один лист, два столбца **Аккаунт / Комментарий**, и список ручных проверок.
5. Загрузите проверенный файл. Сервис проверяет уникальность аккаунтов и точное соответствие исходным комментариям. Условия участия оцениваются вне сервиса; прежний словарь локаций не применяется к загруженному отбору.
6. Укажите название, число основных мест (1–50) и резерва (0–50), сохраните ручные проверки. Подтвердите состав. «Снять видео и выбрать всех» записывает сцену 1920×1080 и выбирает места по порядку. Можно выбирать по одному. WebM скачивается после завершения; сохраните его перед закрытием вкладки.
7. В архиве доступны основные победители, резерв, участники с комментариями, исходный Excel, условия и протокол. Загруженный исходный файл сохраняется и скачивается без изменений, включая все его столбцы. Для старых конкурсов, в которых сохранились только комментарии, доступна таблица комментариев. Нажмите кандидата для записи результата ручной проверки.

При замене исходного Excel сбрасываются промпт и отбор, условия сохраняются. При изменении условий также нужны новый промпт и повторная проверка. После фиксации розыгрыша исходные данные и число мест неизменяемы. Отметка друга не подтверждает пересылку; лайк, подписку, сохранение и Direct проверяет менеджер по подтверждениям.

Сервис не обращается к Instagram за комментариями. Полноту исходной выгрузки сверяет менеджер. Подключение Chrome, профиль Instagram и прокси для работы приложения не нужны.

## Локальный запуск

Node.js 24+ либо Docker. Секреты находятся в локальном .env, публичный шаблон — .env.example.

    npm ci
    node scripts/setup.mjs --env-only
    npm start

В другом терминале: node scripts/setup.mjs — открывает форму создания пароля в обычном браузере. Адрес http://127.0.0.1:4310. Хеш пароля сохраняется в data/auth.json.

    docker compose -f compose.local.yml up -d --build
    node scripts/setup.mjs --docker

Docker использует http://127.0.0.1:4311 и отдельный том giveaway-local-data. Развёртывание через Portainer Stack: [DEPLOY.md](DEPLOY.md).

## Проверки и случайность

Перед стартом фиксируются исходные комментарии, выбранные участники, условия и число мест. Сервер создаёт случайный 256-битный ключ. Порядок — Fisher–Yates с HMAC-SHA256 и rejection sampling. Аккаунт выпадает один раз; повтор запроса места возвращает сохранённый результат. Ключ раскрывается после определения всех мест.

    npm test
    npm run test:ui
    npm run test:ui -- --docker
    npm run test:ui -- --docker --source "C:\path\comments.xlsx"
    npm run verify -- audit.json

Браузерный тест использует отдельную базу, случайный пароль и контрольный отбор (не результат проверки условий ИИ). Проверяет загрузку, точность Excel, промпт, замену источника, отбор, розыгрыш 2+1, WebM, ручные проверки, архив и мобильные страницы. Playwright нужен только для разработки и тестов; в рабочем Docker-образе браузера нет.

## Доступ и хранение

Сессии HttpOnly/SameSite, Secure на HTTPS, CSRF, ограничение попыток входа и scrypt-хеш пароля. API и выгрузки доступны после входа. Индексация отключена. XLSX до 10 МБ, после распаковки до 40 МБ, максимум 100 000 строк. Чтение — в отдельном worker с лимитом памяти и времени; формулы в полях аккаунта и комментария отклоняются.

Комментарии и результаты сохраняются в SQLite. Оригиналы XLSX хранятся отдельно от JSON конкурса, в таблице source_files той же базы; загрузка файла и создание/замена черновика выполняются одной транзакцией. Реальные файлы, .env, data/, artifacts/ и резервные копии исключены из Git. Новая версия сохраняет старые конкурсы и протоколы. Автоматической отправки сообщений участникам нет.
