# Случай решает

Веб-приложение для розыгрыша по проверенному списку из Excel с записью вертикального MP4 для Reels

Рабочий сайт: https://giveaway.marshrut-postroen.com / Развёртывание и откат описаны в [DEPLOY.md](DEPLOY.md)

## Как пользоваться

1. Откройте рабочий сайт или запустите локально **«Запустить приложение.cmd»**
2. Войдите с логином **admin** и заданным паролем
3. Откройте **«Участники»**, загрузите Excel или вставьте список, затем нажмите **«Применить список»**
4. Укажите число победителей, при необходимости включите резерв и задайте его количество / Нажмите **«Применить»**
5. Нажмите **«Записать видео»** и оставьте вкладку открытой до завершения записи
6. Ролик автоматически скачается, копия останется в папке `output`

Формат: **MP4 / H.264, 1080 × 1920, 9:16, 30 кадров/с, без звука** / Длительность зависит от числа мест и показана перед записью / Для исходных 5 основных и 5 резервных — 45 секунд

Ролик готов для вставки в монтаж: вступление → отсчёт → последовательное объявление мест → итоговые списки

- Основные места идут первыми, резервные — следом, с подписью **«Резерв»** в интерфейсе и видео
- Резерв можно полностью отключить / В этом случае в видео нет резервных мест или подписей
- Каждый аккаунт занимает только одно место
- Каждое имя показывается отдельно / Длинные списки разбиваются на кадры по 10 мест, каждый итоговый кадр держится не менее восьми секунд
- В видео нет количества участников, кнопок, интерфейса страницы или точек в текстах
- Точки внутри самих никнеймов сохраняются, чтобы аккаунты точно соответствовали Excel

Повторное нажатие скачивает тот же ролик / Если запись была прервана, повторная запись сохраняет участников и порядок мест

Каждая пара настроек «основные + резервные» имеет отдельный результат / Изменение количества не удаляет прошлый результат, возврат к прежним числам восстанавливает его / Настройка 5+5 продолжает использовать исходный сохранённый розыгрыш

## Промпт и инструкция

Под интерфейсом розыгрыша расположены две кнопки

- **Промпт** — условия конкурса подставляются в полный текст задания для проверки комментариев / Готовый текст копируется целиком / Черновик условий сохраняется в этом браузере
- **Инструкция** — шесть шагов от выгрузки комментариев через GramLens до проверки результатов и записи ролика

Шаблон промпта использует имя текущего Excel и количество импортированных строк и уникальных аккаунтов / При ручном вводе полноту исходной выгрузки необходимо проверить отдельно / Эти сведения не выводятся в видео / Проверку через ИИ менеджер выполняет отдельно, прикладывая исходный Excel

## Добавление участников

- Excel: XLSX и XLS, до 20 МБ / Проверяются ячейки A1–J1 первого листа, затем A1–J1 второго, если он есть / Первый заголовок «Аккаунт» или «Имя пользователя» без учёта регистра определяет столбец / Остальные листы и столбцы не участвуют
- Все значения выбранного столбца ниже заголовка становятся участниками / Пустой выбранный столбец, формулы или ошибки ячеек вызывают понятную ошибку / Ошибка загрузки сохраняет текущий список
- Ручной ввод: один участник в строке, до 50 000 строк / Поддерживаются русские имена и другие текстовые значения длиной до 200 символов
- **«Это Instagram аккаунты»** по умолчанию включено / В этом режиме перед именами в интерфейсе и видео добавляется ровно один `@` / При отключении показывается введённое имя / Подсказка доступна при наведении и фокусе на галочке
- Пробелы по краям и пустые строки пропускаются / Повторы объединяются с сообщением о количестве / Instagram-имена сравниваются без начального `@` и без учёта регистра, обычные имена — по точному совпадению
- Текущий список и его режим сохраняются на сервере / Предыдущие списки архивируются в `state/lists` / Список, порядок строк, режим имён и количество мест определяют сохранённый результат / Повторный импорт идентичного списка в том же режиме восстанавливает выбранные места
- Если новый список меньше количества мест, основные и резервные места сокращаются до доступного числа / Настройки можно изменить перед записью
- Импорт требует авторизации / Разбор Excel выполняется в отдельном worker с ограничением времени и памяти / Обновление списка из устаревшей вкладки отклоняется, а уже начатую запись прежнего списка можно завершить

## Авторизация

Логин проверяется на сервере / Пароль хранится только как scrypt-хеш с отдельной случайной солью в `.local/auth.json`, в клиентскую сборку он не попадает

Участники, результаты, настройки, выбор и скачивание видео требуют действующую серверную сессию / Cookie имеет HttpOnly и SameSite=Strict / Сессия действует 8 часов, кнопка «Выйти» завершает её / После перезапуска сервера нужно войти заново

Для новой установки задайте переменную окружения `GIVEAWAY_ADMIN_PASSWORD` и выполните `node scripts/configure-admin.mjs` из папки проекта / Скрипт не перезаписывает существующие учётные данные и не выводит пароль / На сервере с `PUBLIC_URL=https://…` cookie дополнительно имеет флаг Secure, включая работу за обратным прокси

## Участники и результат

- В рабочий список импортирован только столбец «Аккаунт». Комментарии и отмеченные в них друзья не добавляются в розыгрыш.
- Один участник — один шанс / В исходной установке подключён список из 162 аккаунтов, его можно заменить через интерфейс
- Аккаунты выбираются последовательно через `node:crypto.randomInt`, без смещения по модулю и без возвращения выбранного аккаунта в пул / Порядок анимации не влияет на результат
- Выбор записывается атомарно в `.local/draw-<отпечаток списка>-<основные>-<резервные>.json` **до** старта записи / Исходный результат 5+5 использует прежнее имя без суффикса / Параллельные вкладки, перезагрузка и повторный запуск приложения сохраняют все места
- В `output` сохраняются MP4 и JSON с аккаунтами, местами, статусами, временем выбора и SHA-256 списка
- Версия оформления включена в имя MP4 — устаревший ролик с предыдущим оформлением не выдаётся после обновления
- При работе на сайте запись отправляется на собственный сервер для преобразования в MP4 / При локальном запуске она остаётся на компьютере / Шрифты включены в проект
- Список участников, авторизация и результаты исключены из Git и Docker-образа / В публичном репозитории находятся только код и вымышленные тестовые аккаунты
- Тестовые розыгрыши изолированы от настоящего результата; пример проверки лежит в `artifacts/test-recording.mp4` и не является результатом вашего конкурса.

## Запуск из терминала

Нужны Node.js 22.12+ или 24+, а также FFmpeg с кодеком libx264 в PATH. На этом компьютере они уже установлены. Поддержанный и проверенный браузер — настольный Google Chrome; запись также рассчитана на Edge. Если кодирование недоступно, приложение сообщит об этом до выбора победителя.

```powershell
npm install
npm run build
npm start
```

Для разработки: `npm run dev`. Стандартный адрес — http://localhost:5173. По умолчанию сервер слушает локальный интерфейс / Для контейнера используются `HOST=0.0.0.0`, `PORT=4310` и явный `PUBLIC_URL` / `FFMPEG_PATH` позволяет указать полный путь к FFmpeg

Перед первым запуском импортируйте Excel и настройте пароль / `GIVEAWAY_PARTICIPANTS_FILE`, `GIVEAWAY_STATE_DIR`, `GIVEAWAY_OUTPUT_DIR` задают пути к закрытым данным / Их значения по умолчанию: `data/participants.json`, `.local` и `output`

Повторный импорт Excel, если список обновился:

```powershell
python -m pip install openpyxl
python scripts/import-participants.py "C:\Users\dev\Downloads\Участники_прошедшие_проверку_совместимый.xlsx"
```

После импорта перезапустите сервер. Изменившийся список получит отдельный файл результата; прежний результат сохраняется. Не удаляйте `.local`, если нужно сохранить уже выбранного победителя.

## Проверки

```powershell
npm test
npm run build
npm run test:browser
```

Браузерная проверка требует установленный Chrome и `ffprobe`/`ffmpeg` / Она запускает отдельный сервер на порту 5184 с временными данными, проверяет мобильную и настольную вёрстку, управление клавиатурой, прерывание записи, повторное скачивание и реальный экспорт

Проверяется вход, отказ при неверном пароле, закрытие API и видео без сессии, настройки 2+1 и 1+0, реальные MP4 длительностью 22 и 16 секунд, 1080×1920, H.264/yuv420p и отсутствие аудиодорожки / Проверяются имена и места, отключение резерва во всех кадрах, полный промпт, копирование в буфер и инструкция

Визуальное направление описано в `DESIGN.md`. Шрифты Roboto Condensed и Golos Text используются по OFL; тексты лицензий — в `public/fonts`.
