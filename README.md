# Конкурсы Маршрут-Построен

Закрытое приложение для менеджеров. Фирменные шрифты Dexa Pro, сбор Instagram-комментариев, Excel, промпт для внешней проверки в ИИ и случайный розыгрыш с записью видео.

## Работа менеджера

1. «Провести новый конкурс» → ссылка на рилс → сбор комментариев.
2. Скачать `.xlsx` со всеми собранными строками. Ровно два столбца: **Аккаунт**, **Комментарий**. Предварительного отбора нет.
3. Ввести произвольные условия, нажать «Создать промпт», скопировать промпт и отправить вместе с Excel в ChatGPT с анализом файлов.
4. Проверить отчёт ИИ, загрузить его `.xlsx` обратно. Сервис проверяет соответствие исходной выгрузке и уникальность аккаунтов, не запускает старый словарь локаций.
5. Указать название, количество основных мест (1–50) и резервных (0–50), сохранить список ручных проверок. Подтвердить состав и открыть розыгрыш.
6. Выбрать все места с видеозаписью или по одному. WebM 1920×1080 записывает только сцену и скачивается после завершения. Сохраните файл до закрытия вкладки.
7. «Прошедшие конкурсы» → победители, резерв, таблица участников, исходный Excel, условия и протокол. Нажатие на кандидата открывает ручную проверку.

Новые условия требуют повторного создания промпта и нового проверенного файла. Комментарии сохраняются без исправления опечаток. ИИ получает указание учитывать смысл, синонимы и очевидные опечатки. При правиле «один аккаунт — один комментарий» он должен исключать аккаунты с несколькими исходными комментариями. Отметка друга не подтверждает отправку в Direct.

## Запуск

Node.js 24+, Chrome для Windows, Docker Desktop для Docker-варианта.

```powershell
npm ci
node scripts/setup.mjs --env-only
npm start
```

В другом терминале: `node scripts/setup.mjs`. Откроется форма создания пароля для `admin`. `.env` создаётся локально с одноразовым секретом, хеш пароля сохраняется в `data/auth.json`.

Docker: `docker compose -f compose.local.yml up -d --build`, затем `node scripts/setup.mjs --docker`. Адрес http://127.0.0.1:4311. Обычный локальный запуск: http://127.0.0.1:4310.

Подробное развёртывание через GitHub, Portainer Stack и существующий Nginx Proxy Manager: [DEPLOY.md](DEPLOY.md).

## Полнота сбора

Сборщик прокручивает внутренний контейнер комментариев и сохраняет записи по Instagram ID до и после загрузки каждой порции. Останавливается после устойчивого конца списка. Сохраняет контрольные выгрузки в `data/collections/`. Счётчик Instagram может отличаться от числа доступных записей; сервис показывает расхождение. Решение провести конкурс по такой выборке требует отдельной отметки менеджера и сохраняется в протоколе. Не объявляет неполный сбор полным.

Если серверному IP запрещён доступ: `npm run collect -- --url https://www.instagram.com/reel/CODE/ --out comments.json`, затем импорт JSON в приложении. Вход в Instagram при необходимости выполняется пользователем в отдельном окне Chrome.

## Как сохраняется случайность

Перед стартом фиксируются исходные комментарии, выбранные участники, условия, число мест и ручные проверки. Случайный 256-битный ключ создаётся на сервере. Порядок определяется Fisher–Yates с HMAC-SHA256 и rejection sampling. Каждый аккаунт выпадает максимум один раз. Повторный HTTP-запрос того же места возвращает сохранённый результат. Ключ раскрывается после всех мест.

```powershell
npm run verify -- audit.json
npm test
npm run test:ui
```

Тесты используют отдельные базы и вымышленные аккаунты. Браузерная проверка проходит вход, Excel, новый промпт, обратный импорт, розыгрыш 2+1, WebM, ручную проверку, архив, мобильный экран и выход. В приложении нет автоматической отправки сообщений участникам.

## Доступ и данные

Сессии HttpOnly/SameSite, Secure на HTTPS, CSRF, ограничение попыток входа, scrypt-хеш пароля. API и выгрузки требуют авторизации. Excel читается в отдельном worker с ограничениями размера архива и времени; формулы отклоняются. В репозитории нет реальных комментариев, cookie, паролей и записей конкурсов. `data/`, `.env`, `artifacts/` исключены из Git. Данные сохраняются в SQLite / Docker volume; перед обновлением делайте резервную копию.
