# Развёртывание

Сайт: https://giveaway.marshrut-postroen.com · сервер 185.72.147.187.

Рабочий Portainer Stack — **marshrut-giveaway**. Обновляется только этот Stack. Существующая запись Nginx Proxy Manager направляет домен на http://185.72.147.187:9998; Docker публикует 9998:4310, сеть web. DNS, Nginx и другие сервисы при обновлении приложения менять не нужно. Caddy не требуется.

## Настройки Stack

- Repository: https://github.com/Studio313-krd/marshrut-postroen-giveaway-manager.git
- Reference: refs/heads/main
- Compose path: docker-compose.yml
- PROXY_NETWORK=web
- Существующий том: **marshrut-giveaway_giveaway-data**. Не удалять и не переименовывать.

Для нового окружения используйте случайный SETUP_TOKEN длиной от 32 символов либо заранее подготовленный ADMIN_PASSWORD_HASH. На существующем сайте пароль уже записан в томе; сохраняйте настройки доступа. .env.example — публичный шаблон, настоящие значения вводятся в Portainer и не коммитятся.

При первичной настройке ссылка https://giveaway.marshrut-postroen.com/#setup=ТОКЕН открывает форму пароля для admin. Не публикуйте эту ссылку. После настройки вход обычный, без токена.

## Обновление

1. Сохраните резервную копию базы и авторизации. Для работающей SQLite используйте backup / VACUUM INTO; не копируйте только основной файл при активном WAL. Альтернатива — копия всего тома при остановленном приложении.
2. Выполните проверки, commit и push в GitHub.
3. Portainer → Stacks → **marshrut-giveaway** → **Pull and redeploy**. Дождитесь окончания сборки. pull_policy: build пересобирает образ.
4. Проверьте healthy, HTTPS и вход. /healthz возвращает ok:true, /api/contests без авторизации — 401. После перезапуска потребуется войти заново; конкурсы, результаты и пароль сохраняются.
5. Создайте конкурс загрузкой исходного Excel из GramLens. Проверьте число строк, промпт для того же файла, импорт отбора и архив. Убедитесь, что остальные контейнеры остались в прежнем состоянии.

Версия с импортом Excel не запускает браузер и не обращается к Instagram. Настройки COLLECTOR_* и локальный помощник больше не используются. Ранее сохранённые данные остаются в томе. Откат — предыдущий Git commit с тем же томом; замена исходной выгрузки в черновике требует повторной проверки условий независимо от версии.

Версия 3.1 создаёт конкурс сразу из файла, без ссылки, и сохраняет оригинал XLSX в таблицу source_files базы SQLite. Резервная копия всей базы включает и эти файлы. Миграция добавляет таблицу; завершённые розыгрыши остаются неизменными. Сохранённые промпты незавершённых конкурсов обновляются под работу с исходной выгрузкой.

## Локальный Docker и тесты

    npm ci
    node scripts/setup.mjs --env-only
    docker compose -f compose.local.yml up -d --build
    node scripts/setup.mjs --docker

Адрес http://127.0.0.1:4311. .env исключён из Git и Docker build context. Локальный том отделён от рабочего сайта.

    docker build -t contest-marshrut-postroen-giveaway .
    npm test
    npm run test:ui -- --docker --source "C:\path\comments.xlsx"

Браузерная проверка запускает отдельный временный контейнер на 127.0.0.1:14312 с отдельной базой и паролем. Текущие server/ и public/ подключаются только для чтения. Если --source не указан, создаётся контрольный Excel формата внешней программы. Рабочие розыгрыши при тесте не запускаются.
